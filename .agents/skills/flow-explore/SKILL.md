# 调查现状

## 输入

待回答的问题、允许调查的对象与已有线索。先读工作区入口与目标仓适用规则；仅入口缺失、多仓歧义或路径变化时读 [上下文规范](../../../docs/context.md)。

## 动作

- **定向取证**：围绕核心问题读取相关源码、配置、日志与记录，优先寻找能区分假设的直接证据，不做全仓考古；同步核对文档描述与源码现状是否一致。
- **区分事实与未知**：分开陈述已确认事实（附具体文件路径或证据来源）、合理推断与仍缺证据的未知项；未查到的范围不等同于不存在。
- **严格只读**：不改业务代码，不执行远端写操作或有副作用的实验，不擅自安装工具或访问未授权环境。
- **按需落盘**：问题答清即可直接回复结束。仅在需独立审阅或长期复用时读 [文档规范](../../../docs/documents.md)，选用项目已有模板或 [调查模板](../../../templates/investigation.md)。

## 产出

直接给出结论、关键来源、成立前提、未决未知与最小下一步；后续若需设计方案再交由 `flow-plan`，不把调查假设写成已定方案。

## 停止与恢复

问题答清即停，不强制转入规划或实施。关键来源缺失、目标不唯一或验证需越过只读边界时，说明具体缺口并仅询问影响结论的选择；续作恢复时先核对相关文件是否变化。
