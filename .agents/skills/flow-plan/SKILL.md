# 明确方案

## 输入

目标、验收、范围与非目标、已有事实和约束。已有有效方案直接复用；明确的小改不补造需求、设计和计划全套文档。

## 动作

- 只澄清会改变目标、范围、关键方案、验收或外部影响的未决项；可做当前决策所需的定向读取，重要未知需独立调查时使用 `flow-explore`。
- 选择最小充分方案，必要时比较真实备选，指出兼容、失败处理和主要风险。复杂安全、迁移、性能、界面或接口文档按项目规则或已选专业能力处理，不在此包办领域规范。
- 仅因独立依赖、协作或风险拆任务；为任务说明结果、范围、直接依赖与可观察验证，包括必要反例和环境条件。选择检查时按需读 [验证规范](../../../docs/verification.md)。
- 执行方式沿用有效授权，未选择时默认当前 checkout、单 Agent。用户选择 worktree、多 Agent 或需要变更/恢复安排时读 [执行规范](../../../docs/execution.md)，记录真实目录、分工、依赖、结果整合与最终验收目标；这里只形成安排，不创建 worktree、不派发 Agent。
- 只有需持久记录或独立审阅时读 [文档规范](../../../docs/documents.md)。优先复用已有记录，否则从 [工作记录](../../../templates/work.md)、[需求](../../../templates/requirements.md)、[设计](../../../templates/design.md)、[计划](../../../templates/plan.md) 中只选必要模板；已独立维护的规格和任务只引用，不双写。

## 产出

必要的方案与取舍、验收方式、任务依赖、执行安排和待决定项。简单工作可直接回复；记录的安排不等于动作已发生，也不扩大实际授权。

## 停止与恢复

方案足以执行且授权已覆盖时可继续 `flow-execute`，不因换 Skill 重复审批。影响执行的关键选择未决时停在该边界，独立且已授权的工作可继续。接手先核对当前目标、权威方案及未关闭项；依据变化才修订并说明影响，不凭旧聊天重建计划。
