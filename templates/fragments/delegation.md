# 委派输入片段

> 用于获准委派后的任务提示或消息，不默认落盘。先读取宿主提供的角色配置及说明，再选择启动配置；没有配置能力时明确使用宿主默认或用户指定配置，必需配置不可读时报告阻塞。角色和任务必须写入提示，不能只靠配置名称或备注。例如 Paseo 可读取 profiles 与 notes，并把任务写入 initialPrompt。填入实际信息，删去无关条件项，不编造授权。

- 角色与唯一目标：明确本次职责及要返回的结果。
- 实际位置：目标仓、真实 checkout/目录、适用规则与必要来源；有基线要求时说明核实的版本，不用拟创建位置冒充实际位置。
- 允许范围：可读取/修改的路径、授权边界及禁止副作用；纯分析则明确只读。
- 依赖与写入时段：直接依赖、稳定输入、何时允许写入/须等待谁；同 checkout 同时一个写入者，主 Agent 也计入。
- 验收与检查：本任务可观察结果、必要验证入口、已有证据及其适用性，不要求补造无关阶段文档。
- 返回要求：实际产物、来源、检查/结果、覆盖/限制、未关闭项和安全下一步，可参照 [结果片段](task-result.md)。
- 职责限制：不扩大范围、不再次委派、不接管整项工作；主记录由协调者维护。结束报告是否已停止写入；状态未知先核对，不重复启动写入者。

> 不因使用片段获得委派授权。多 Agent 的实际派发/回收按 [执行参考](../../.agents/skills/flow-execute/references/multi-agent.md)，不复制全部历史或为每个任务建立交接文件。
