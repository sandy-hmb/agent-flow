# 按需模板索引

仅在真正落盘时读取当前模板，不预读或生成全套文件。先按 [文档规范](../docs/documents.md) 复用项目文件、用户要求或已选扩展模板，再选公共模板；没有持久记录需要时直接回复即可。

| 模板 | 用途与触发条件 | 写入者 | 最低信息 | 更新方式 |
| --- | --- | --- | --- | --- |
| [workspace](workspace.md) | 需要独立项目入口，已有入口不足时 | 项目维护者 | 项目范围、工作流根与目标根、规则/事实入口 | 来源或路由变化时原地更新，不登记全部仓 |
| [repository](repository.md) | 仓事实复杂且现有说明不足时 | 项目维护者 | 实际路径、职责、适用规则、已有检查入口及未知 | 仅在相关事实变化时更新，不复制仓手册 |
| [work](work.md) | 普通任务需跨会话或持久记录时 | 协调者；单 Agent 时为当前执行者 | 目标/验收或权威引用、必要依据、当前进展、证据/缺口、下一步 | 连续原地维护，不建每阶段副本 |
| [investigation](investigation.md) | 调查有独立读者、复用价值或长正文时 | 调查者 | 问题、范围、来源、事实/推断/未知、结论与限制 | 来源或结论实质变化时更新，说明适用时点 |
| [requirements](requirements.md) | 需求与验收需独立审阅/维护时 | 方案负责人 | 来源、范围/非目标、约束、可观察验收、待决定项 | 需求变化时更新，说明影响，不重复实施步骤 |
| [design](design.md) | 关键方案需独立审阅/维护时 | 方案负责人 | 需求引用、所选方案/理由、关键影响、风险与验证方向 | 关键决策变化时更新，不复制需求正文 |
| [plan](plan.md) | 有独立任务、依赖或协作交接时 | 协调者/计划维护者 | 规格引用、任务范围/结果/依赖/验证、必要执行安排 | 任务或安排变化时更新；进展在工作记录维护 |
| [verification](verification.md) | 验证需独立交付或证据复杂时 | 核验者 | 验收引用、实际目标/输入、检查/证据、结论/缺口 | 实际输入或覆盖变化时更新，不复制原始日志 |

模板正文中的引用块是写作提示，生成产物时删除。最低信息不能凭空补齐：未核实则写未知及影响，未执行不填通过，未批准不写批准。条件章节无关时删除；相关风险和缺口不得删除。标题可按项目命名，不强制路径、编号、日期或状态字段。

默认一份工作记录足够。独立规格生成后成为该内容权威，工作记录只留引用和当前事实；执行安排仅在工作记录或独立计划择一维护，完整人工验证说明同样只维护一处。已有有效设计可直接实施，不补造缺失的需求或计划。

[委派片段](fragments/delegation.md) 和 [结果片段](fragments/task-result.md) 通常用于提示/消息，不是默认落盘文件；不用它们生成每任务 `handoff.md` 或 `result.md`。专业模板由已选扩展自身提供，不复制到公共模板库。
