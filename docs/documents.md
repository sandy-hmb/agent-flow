# 文档与记录

首次生成或实质修改正式文档时读取；同会话按变化补读，简单任务直接回复，不默认落盘。

## 是否需要文档

- 需要跨会话续作、独立读者审阅或长期复用的复杂任务才持久记录；优先原地更新项目已有文件，没有适用位置再新建，不迁入无关目录。
- 常规任务维护一份 `work.md` 即可承载目标验收、关键方案与验证结果：仅关键技术取舍或跨模块契约需独立审阅时拆 `design.md`，多任务依赖或协作交接时拆 `plan.md`，独立排障/分析交付时用 `investigation.md`。
- `requirements.md`、`verification.md`、`repository.md` 属于低频独立交付模板，仅在用户或项目明确要求独立成文时启用，严禁按阶段凑齐整套文档。优先满足项目约定与已选扩展模板，其余按 [模板索引](../templates/README.md) 在落盘前只读当前所需的一种。

## 内容归属

| 内容 | 唯一维护位置 |
| --- | --- |
| 常规任务的目标、验收、关键方案与当前状态 | 现有任务记录；新建时使用 `work.md` |
| 已拆出的调查、设计、计划（或明确要求的独立需求/验证） | 对应正式文档；`work.md` 只保留链接、当前结论与变更影响 |
| 执行安排 | 有独立 `plan.md` 时在计划中，否则在 `work.md`；另一处只链接 |
| 执行进展、未关闭项与下一步 | `work.md` 顶部的 `## 当前概览`；不在 `plan.md` 维护可变状态表 |
| 最新验证结论、缺口与原始报告 | 结论与缺口写在 `work.md`（或明确要求的独立验证文档）；原始日志留原处引用，不复制全量输出 |

协作时由协调者维护主记录，子任务返回事实经核对后合入；扩展产物不覆盖已批准主规格。`design.md` 维护技术规则、契约与取舍；`plan.md` 维护任务边界、交付物、直接依赖、规格章节引用与验证入口，不重述设计中的算法、字段或完整测试矩阵。

已确认的目标或关键方案变化后，原地更新受影响的权威内容、任务与验收，明确旧结论的失效范围；未受影响的内容和证据继续复用。

## 控制工作记录体积

`work.md` 是**当前有效现场快照**，不是按轮次追加的操作流水账。多轮迭代时必须原地覆盖过时内容：

1. **`## 当前概览` 严格控制在 5～8 行以内**：仅列出当前阶段与结论、分支与提交/PR（适用时）、核心产物入口、未关闭项与唯一安全下一步；每次更新直接覆盖旧状态，不在概览或文末追加多轮经过。
2. **`## 实际验证` 只保留当前有效版本的最新结果与缺口**：代码或方案更新后，原地替换已作废轮次的测试子章节；不堆叠历史失败轮次，不粘贴大段终端输出。
3. **`## 关键里程碑` 仅记影响决策或恢复的单行转折**：已作废轮次的排查、回退或方案调整，仅在对后续判断或恢复确有必要时浓缩为 `- YYYY-MM-DD：结论与影响（依据）` 单行记录；常规推进不入账。

## 真实性与精简准则

- **单一真实性边界**：只写已核实事实、真实执行结果与实际缺口；未核实标明未知，未执行不写通过，建议或计划不写成已获批或已执行。模板与文档正文不构成越权操作依据。
- **禁止机械免责套话**：正文聚焦核心结论、方案取舍、接口契约与可执行动作。仅在确有未验证范围、环境缺失或外部依赖时点明具体缺口，**不在各章节末尾反复附加“本地结果不等于外部上线/计划不代表已执行/推荐不等于已授权”等防御性声明**。
- **按风险控制详略**：高猜错代价点（兼容、数据、安全、跨模块契约）写清规则，低风险实现细节留给实施者；新增复杂性的必要性按 [flow-plan](../.agents/skills/flow-plan/SKILL.md) 判断，具体写法可按需参考 [按需写作示例](examples/document-quality/README.md)。
- **原地洁净维护**：同一文档原地更新，不建 `final`、`v2` 或日期副本；落盘时删净模板 `>` 提示、占位与不适用条件章节。不写入凭据与无关个人数据；相对链接从当前文件所在目录解析并确保有效。

## 接手与自审

- 暂停或交接时在 `## 当前概览` 写清未完成改动、活动写入者及恢复前需核实的现场；新会话接手先核对真实目录、分支提交与代码状态。
- 落盘后原地自查：顶部能否直接读出当前状态与下一步、是否残留已作废轮次流水或重复免责套话、引用链接是否有效、有无跨文件双写；发现问题直接修原文，不另出检查报告。完成与证据判断见 [验证规范](verification.md)。

## 维护规则与示例

按失败类型选择表达：越权风险给清晰边界，产物结构靠简洁正向槽位引导，不在多处重复叮嘱同一禁令；可机械验证的结构用维护检查保障，不用关键词测试代替语义判断。示例只补充难以从规则直观理解的写法，同一要求只保留一处权威定义。
