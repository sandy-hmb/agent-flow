# 上下文与来源

仅在工作区入口缺失、多仓路由或目标存在歧义、路径失效、跨仓切换或规则冲突时读取；目标唯一明确的单仓常规任务按 `AGENTS.md` 快路径直接进入对应 Skill。

## 工作区入口

- **资源根与目标根分离**：工作流资源根是本仓 `AGENTS.md`、四个 Skill、`docs/`、`templates/` 所在目录；目标项目根是本次调查或修改的业务仓，终端停在资源根不代表业务目标就是本仓。
- **入口解析与缺失处理**：默认读取 `<工作流资源根>/.workspace/workspace.md`，用户或宿主显式绑定其他入口时读取绑定文件（初始化见 [README](../README.md)）。未显式绑定且默认入口不存在时，可直接按用户明确指定的目标执行，不强制初始化；**显式绑定的入口缺失或命中仓路径不存在时，直接报告缺口并停止，严禁静默回退默认入口或扫描相邻目录**。
- **同名文件隔离**：目标仓内部的同名 workspace 文件仅在该仓规则明确引用时读取，不替换工作区入口，也不递归搜索。

## 定位当前目标

按以下优先级唯一定位目标（列入索引仅用于定位，不授予所有仓的读写权限）：

1. 用户本次明确指定的目标，包括维护 Agent Flow 自身。
2. 已明确的当前任务记录所指向的目标；未给完整路径时可先按 `.workspace/items/` 目录名匹配候选并只读其顶部 `## 当前概览` 确认，存在多个候选且无法区分时再询问，不按修改时间猜测或遍历全部历史正文。
3. 工作区入口中命中的任务路由，其次默认目标（仅配置唯一仓时直接选用该仓）；多条路由冲突或无默认且多仓并存时先询问，确认前不遍历各仓源码。

## 按需读取与冲突处理

- **按涉及仓加载**：先读本次涉及仓的适用规则与概览，再定向读取相关代码与记录；不遍历索引内无关仓。同会话复用未变内容；新会话或上下文发生压缩截断时，先重读当前任务概览、分支提交与未关闭项。
- **权威与事实冲突**：上层指令、用户授权与项目规范约束行动边界，下层或扩展规则不能扩大权限；文档描述与源码实现不一致、或多份资料冲突时，保留事实差异与来源依据，不把较新日期或文档描述盲目当作现状。

## 路径与可用性

相对路径（仓路径、规则入口与 Markdown 链接）统一从**声明文件自身所在目录**解析。四个核心 Skill 引用 `../../../docs/` 与 `../../../templates/`，依赖本仓完整目录结构；单独复制 `SKILL.md` 时须同步处理依赖链接。无原生 Skill 发现能力的宿主直接按路径读取对应 Markdown。
